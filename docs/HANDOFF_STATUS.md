## 建议接续顺序

1. 安装依赖并启动游戏，复测基线；读取车辆参考图评审。
2. 用 Blender MCP 完成统一左舵、内外一致的整车与驾驶位；保存源文件并导入游戏。
3. 对照参考图验证造型、空间、仪表、方向盘、视野和乘坐感。
4. 验证不同地貌、季节、时段及转场，改善宏大景观与自然道路。
5. 做真实连续驾驶、性能和独立视觉评审，持续修正到完整交付。

以上顺序供参考；实现方案由接续 AI 自行判断。
