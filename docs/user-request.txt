https://patch.gg/blendi/oil-paint

**2. PROCEDURAL WORLD GENERATION — Slow Roads**

The GOAL is simple:

**Take the infinite procedural terrain and road-generation experience of Slow Roads, render the entire world using the actual painterly rendering techniques from Blendi's Oil Paint, and let the player experience everything from inside a vehicle, like Euro Truck Simulator 2.**

Imagine driving a camper van through an endless, beautiful, three-dimensional oil painting.

Not a tech demo. Not a rough prototype. Build a beautiful, playable, continuously generated driving experience with professional-quality rendering and satisfying first-person immersion.

# Non-negotiable constraints

**Stack:** Vite + Three.js, TypeScript, ES modules, WebGL2. Preserve compatibility with the original Oil Paint renderer, which was built using Three.js 0.186.

The complete project must run with:

`npm install && npm run dev`

**Source-first development:** Before implementing anything, visit all three references and study their actual content. Do not attempt to recreate these systems from vague descriptions when existing documentation or appropriately licensed source code is available.

**Assets:** Generate the world, road, vegetation, vehicle, and cabin geometry procedurally wherever practical. Reuse the MIT-licensed Oil Paint rendering code and compatible CC0 assets if useful, preserving their license notices. Do not depend on paid asset packs or unlicensed models.

**Performance:** Target a stable 60fps on a MacBook M5 Pro running Chrome, with Retina-resolution rendering. Use chunk streaming, geometry instancing, LOD, efficient shader execution, and adaptive resolution as needed.

Performance and visual quality are equally important.

# Step 1 — Research and extract the reference systems

This is mandatory. Do not begin building the game until you have investigated the references.

## Reference A: Blendi's Oil Paint

https://patch.gg/blendi/oil-paint

This reference defines the FINAL ART DIRECTION.

The project publicly documents its rendering architecture and identifies its code as MIT-licensed.

Read its README, source files, shader implementations, rendering pipeline, and technical documentation.

Study and reuse the actual renderer wherever the license permits.

Important source areas include:

- `src/oilpaint/dabs.js`
- `src/oilpaint/brush.js`
- `src/oilpaint/common.js`
- `src/oilpaint/ground.js`
- `src/oilpaint/pins.js`
- `src/oilpaint/shade.js`
- `src/oilpaint/finish.js`

Understand how the renderer produces actual painted brushstrokes attached to 3D geometry.

Study its world-space brushstroke placement, color mixing, ground rendering, atmospheric effects, shading, and distance-dependent stroke density.

**Do not replace this system with a generic cartoon shader, simple cel shading, or a screen-space oil-paint filter.**

The defining feature is that the world itself is constructed and rendered through brushstrokes that remain attached to the geometry as the camera moves.

Adapt this rendering architecture to our procedural road-trip environment.

Preserve the core visual behavior of the original Oil Paint renderer while extending it to support much larger, continuously generated landscapes.

## Reference B: Slow Roads

https://slowroads.io/

This reference defines the PROCEDURAL WORLD GENERATION SYSTEM.

Study the game, its official documentation, publicly available technical explanations, and any source code the original author has explicitly released for reuse.

Investigate:

- How infinite terrain is generated.
- How heightmaps are produced.
- How road paths are generated through the landscape.
- How terrain and road geometry are integrated.
- How terrain chunks are loaded and unloaded.
- How distant landscapes are rendered.
- How repeated terrain patterns are avoided.
- How continuous driving is supported.
- How performance and memory usage are controlled.

If authorized original source code is available under a suitable license, study and reuse the relevant algorithms according to that license.

If the original implementation is not publicly licensed, analyze its documented methods and observable behavior, then independently implement equivalent procedural-generation systems.

Do not confuse third-party clones with the original author's source code or assume proprietary browser bundles are open source.

**The GOAL is to reproduce the procedural behavior and engineering quality of Slow Roads, not merely create a landscape that vaguely resembles it.**

The final game should retain the same essential experience: an endlessly extending road traveling through continuously generated scenery.

## Reference C: Euro Truck Simulator 2

This reference defines the FIRST-PERSON DRIVING EXPERIENCE.

Study actual gameplay footage and screenshots showing the interior cabin camera.

Focus on:

# Step 2 — Infinite procedural terrain and roads

Build a world-generation system based on the functional principles demonstrated by Slow Roads.

For the initial version, use only ONE environmental biome:

**Lush green grasslands, rolling hills, wide valleys, open plains, scattered trees, distant mountains, and beautiful skies.**

The landscape should feel enormous, peaceful, naturally composed, and endlessly explorable.

Implement:

- Deterministic terrain generation using world seeds.
- Seamless infinite terrain streaming.
- Natural large-scale heightmap generation.
- Rolling hills, valleys, distant ridgelines, and open plains.
- Continuous terrain chunk loading and unloading.
- Procedural vegetation placement.
- Distant mountain rendering and atmospheric depth.
- Smooth LOD transitions.
- Stable performance during extended driving.

The terrain must not look like raw Perlin noise covered with green material.

Use deliberate landscape composition to create beautiful, memorable views.

Occasionally open up the terrain to reveal enormous valleys, distant mountain ranges, wide fields, and spectacular panoramic views.

## Infinite road generation

Generate a single continuous, naturally winding road that the player can drive along forever.

The road must:

- Extend continuously as the player drives.
- Follow the landscape naturally.
- Have smooth turns, hills, straights, and elevation transitions.
- Maintain a reasonable width and safe driving gradients.
- Integrate seamlessly with the terrain.
- Include natural road shoulders and roadside vegetation.
- Never disconnect, float above the ground, or intersect hills.
- Remain deterministic and consistent across chunk boundaries.

Road routing and terrain generation must be designed together.

Do not generate terrain first and simply place a road mesh on top.

The terrain must adapt naturally to the road where necessary.

**The world should behave like Slow Roads, but visually look like a moving oil painting.**
